# СтейджРент CRM — як зробити з коду реальний сайт

Тут повний код застосунку. Нижче — найпростіший спосіб перетворити його
на справжній сайт зі своєю адресою, без встановлення будь-чого на
комп'ютер. Знадобиться лише браузер і два безкоштовні акаунти.

Важливо розуміти: дані (проекти, склад, клієнти) зараз зберігаються
**в браузері того пристрою**, з якого ви заходите на сайт — так само,
як історія переглядів. Це означає, що застосунок буде повноцінно
працювати одноосібно з одного комп'ютера/браузера. Якщо згодом
знадобиться, щоб кілька людей бачили одні й ті самі дані з різних
пристроїв — це окремий крок (підключення спільної бази даних), і я
можу допомогти з цим пізніше.

## Крок 1. Акаунт на GitHub (де лежатиме код)

1. Зайдіть на https://github.com і зареєструйтесь (безкоштовно).
2. Натисніть "New repository", дайте назву, наприклад `rental-crm`,
   залиште "Public" або "Private" — не важливо, і натисніть "Create repository".
3. На сторінці репозиторію натисніть "uploading an existing file" і
   перетягніть туди **всі файли та папки з цього проєкту** (збережіть
   структуру папок — `src` має лишитись папкою).
4. Натисніть "Commit changes".

## Крок 2. Акаунт на Vercel (де сайт буде "жити")

1. Зайдіть на https://vercel.com і зареєструйтесь через кнопку
   "Continue with GitHub" — так акаунти одразу з'єднаються.
2. Натисніть "Add New… → Project".
3. Оберіть щойно створений репозиторій `rental-crm` і натисніть "Import".
4. Vercel сам розпізнає, що це проєкт на Vite — нічого змінювати не треба,
   просто натисніть "Deploy".
5. Через 1–2 хвилини отримаєте посилання на кшталт
   `rental-crm-xxxx.vercel.app` — це і є ваш сайт.

## Готово

Тепер застосунок доступний за цим посиланням у будь-який момент —
можна зберегти в закладки або на головний екран телефону, він
поводитиметься як звичайний сайт/застосунок.

Якщо після цього захочете:
- власну адресу (наприклад `crm.вашакомпанія.com`) — додається в
  налаштуваннях Vercel, "Domains";
- доступ для кількох співробітників з різних пристроїв до одних і тих
  самих даних — напишіть мені, підключимо безкоштовну хмарну базу
  даних (Supabase) замість зберігання в браузері.
